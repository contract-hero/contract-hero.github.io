Claude Code plugins

Plugins for Sui Move and developer tooling.

A small set of Claude Code plugins — Sui Move tooling with bundled docs and an LSP-backed MCP server, a multi-agent build system, a bridge to OpenAI Codex, an HTML deliverables toolkit, and interactive coding courses that run inside a session. 

# in a Claude Code session
/plugin marketplace add contract-hero/plugin-marketplace
/plugin install sui-pilot@contract-hero

Developer tooling

Sui Move stack helpers and general-purpose Claude Code extensions.

sui-pilot

Sui Move development plugin

LSP integration, bundled docs (Sui, Walrus, Seal, TS SDK, Move Book, sui-prover), code quality and review skills, plus formal-verification specs.

Visit site → Repo

code-forge

Multi-agent build system

TDD-as-phase orchestration with script-coordinated parallel review, a best-of-N implementer, and the forge-guard hook for discipline.

Visit site → Repo

codex-bridge

Bridge to OpenAI Codex CLI

/codex for direct calls and /claudex for multi-round Claude ↔ Codex prompt refinement before plan-mode execution.

View repo →

toolkit

HTML deliverable toolkit

Bundles html-artifact (one-off visual deliverables), publish-html (turn a local .html into a shareable URL), for-dummies (auto-derived intros), and move-call-chains.

View repo →

Courses

A learning framework (Agentic Community College) plus content plugins that teach specific domains end-to-end.

agentic-community-college

Learning framework

Runs reference-seeded coding lessons through MCP. Ships course-engine, course-conductor, course-creator, and lesson-creator skills with a declarative probe runtime.

Visit site → Repo

acc-deepbook-course

Sui DeepBook course

Hands-on lessons that walk learners through building Sui DeepBook integrations end-to-end. Requires the agentic-community-college plugin to run.

Visit site → Repo

acc-evm-wal

Walrus storage on EVM

A short Foundry-based lesson that teaches Walrus decentralized storage by walking learners through building a WalrusAnchor Solidity contract.
