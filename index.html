04Claude Code plugins

All of them install from one marketplace: /plugin marketplace add contract-hero/plugin-marketplace. Browse the marketplace page.

  • sui-pilot

    Claude Code plugin for the full Sui stack: bundled docs across 6 corpora, a Move LSP bridge, a Sui Prover wrapper, commands and skills for code quality, security review and verification.

    repoSuiMove

  • code-forge

    Multi-agent build system: design spec, interactive architecture playground and docs.

    repoagents

  • agentic-community-college

    Course runtime for Claude Code: a course plugin splits a lesson into chapters defined by tests, and a conductor agent implements each chapter in a seeded workspace. An exploratory proof of concept.

    repoMCPcourses

  • toolkit

    Self-contained HTML deliverable skills: html-artifact, publish-html, for-dummies, move-call-chains.

    skills

  • skypie

    The Sky Pie plugin: MCP server launcher, pairing hook and an artifact-links skill. /plugin install skypie@contract-hero

    MCP

  • codex-bridge

    Bridge to the OpenAI Codex CLI from Claude Code: /codex execution and /claudex multi-round prompt refinement.

    Codex

  • sui-agent-tank private

    Not public yet.

    Sui
